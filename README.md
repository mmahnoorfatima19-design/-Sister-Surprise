# 🌸 Sister Surprise Interactive Web Experience

An aesthetic, romantic, and interactive web application designed to create a heartwarming surprise for sisters. Built with clean HTML5, CSS3, and modern JavaScript, featuring smooth animations, realistic blooming floral transitions, passcode protection, and interactive polaroid memories.

---

## ✨ Features

- 🎁 **Interactive Gift Cover:** Elegant ribbon gift box with tap-to-open gesture.
- 🌹 **Realistic Blooming Rose Portal:** Full-screen multi-layered rose vortex transition.
- 🔒 **Heart Lock Passkey:** Custom 4-digit PIN lock screen (`1234` default) with keypad dialer.
- 🌀 **Floral Ring Loader:** Rotating rose circle loader animation upon key validation.
- 🖼️ **Polaroid Memory Gallery:** Interactive polaroid photo cards with full-screen lightbox modal view.
- 📜 **Handwritten Love Letter Section:** Parchment paper styling with wax seal and live customization controls.
- 🌸 **Floating Petal System:** Dynamic background rose petals rendered via HTML5 Canvas.
- 🎵 **Ambient Audio Controls:** Integrated background music player toggle.
